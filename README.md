# Braga & Xavier Advogados — Website Oficial

Website institucional e experiência digital da **Braga & Xavier Advogados**, boutique jurídica sediada em Montes Claros – MG com atuação em todo o território nacional.

## ⚖️ Especialidades
- **Direito Bancário**: Defesa em execuções de títulos, revisão de contratos bancários e renegociação com deságio.
- **Dívidas Empresariais**: Reestruturação de passivos corporativos, proteção de fluxo de caixa e defesa patrimonial de sócios avalistas.
- **Direito Rural e Agronegócio**: Alongamento de dívidas de crédito rural (Manual de Crédito Rural e Súmula 298 do STJ), auditoria de CPRs/CCRs e impenhorabilidade de propriedades rurais.

## 🛠️ Tecnologias
- **Next.js & Node.js**
- **Tailwind CSS**
- **GSAP & ScrollTrigger** (Motion design e animações dinâmicas de scroll)
- **Lenis** (Smooth scroll)
- **Lucide Icons**
- **SEO & Schema.org (JSON-LD)** (LegalService e FAQPage estruturados)

## 🚀 Como Executar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/bragaexaviertech/site.git
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

4. Abra [http://localhost:3000](http://localhost:3000) no seu navegador.
